# Celestial

Клиент Celestial для Minecraft 1.16.5 (MineLegacy): лаунчер, фикс кика при
телепорте и рабочий слом щита топором (`ByPass SB`).

---

## Установка и запуск

Java устанавливать не нужно — она уже внутри лаунчера.

### 1. Скачай лаунчер

Открой раздел **[Releases](../../releases/latest)** и скачай файл
`CelestialLauncher-windows-x64.zip`.

### 2. Распакуй архив

Распакуй в любую папку, например `C:\Celestial`.

> Не запускай `CelestialLauncher.exe` прямо из окна архиватора — сначала
> распакуй, иначе игра не сможет создать файлы рядом с собой.

### 3. Запусти

Открой папку `CelestialLauncher` и запусти **`CelestialLauncher.exe`**.

### 4. Введи ник

В поле «Ник» введи имя, которое будет видно на сервере: 1–16 символов,
латиница, цифры и `_`. Ник запоминается и подставляется при следующем запуске.

### 5. Нажми «Запустить Celestial»

Дальше откроется окно игры. **Первый запуск идёт дольше обычного** — лаунчер
скачивает библиотеки клиента (нужен интернет). Следующие запуски быстрее.

## Если Windows ругается

* **SmartScreen** («Windows защитила ваш компьютер»): нажми **Подробнее** →
  **Выполнить в любом случае**.
* **Антивирус** может пометить неподписанный `.exe`. Добавь папку с лаунчером
  в исключения — файл не заражён, просто сборка без цифровой подписи.

## Что где лежит

| Что | Где |
| --- | --- |
| Настройки, миры, конфиги клиента | папка `run` рядом с лаунчером (обычно `CelestialLauncher\app\run`) |
| Логи игры | `run\logs\latest.log` и окно лаунчера |
| Скачанные библиотеки клиента | `%APPDATA%\CollapseLoader\celestial-libraries` |
| Сохранённый ник | `%USERPROFILE%\.celestial-launcher.properties` |

---

## Обновление

1. Скачай новый `CelestialLauncher-windows-x64.zip` из Releases.
2. Распакуй **поверх** старой папки `CelestialLauncher`.
3. Папку `app\run` (настройки и миры) можно сохранить — просто не удаляй её.

## Частые проблемы

| Проблема | Что делать |
| --- | --- |
| Лаунчер не открывается | Проверь, что архив распакован полностью и путь не содержит запрещённых символов; запусти от имени администратора |
| Нажал «Запустить», игра не появилась | Посмотри лог в окне лаунчера и `run\logs\latest.log`; чаще всего нет интернета при первом запуске |
| Вылет при входе на сервер | Обнови сборку из Releases — в старых версиях был кик из-за телепорта |
| Щит не ломается | В Attack Aura должна быть включена галочка `ByPass SB`, топор — в хотбаре |

## Для разработчиков

### Структура

| Каталог | Содержимое |
| --- | --- |
| `src/` | Исходники лаунчера, бутстрапа и патчей |
| `shieldbreak-src/` | Shadow-классы `rrnD_2`, `rrwI_2` — фикс слома щита (`ByPass SB`) |
| `packettap-src/` | Перехватчик пакетов для отладки |
| `deobf/`, `deobf-final/` | Декомпилированные классы клиента для справки |
| `docs/` | Описание фиксов и аудит деобфускации |
| `libs/` | Библиотеки, с которыми компилируется проект |

`build/`, `run/` и `*.log` в репозиторий не попадают (см. `.gitignore`): это
сгенерированные артефакты и игровые логи, часть файлов там больше лимита
GitHub в 100 МБ.

### Требования

* JDK 21 (`C:\Program Files\Java\jdk-21`)
* Runtime-jar клиента:
  `%APPDATA%\CollapseLoader\celestial-libraries\celestial-client-remapped.jar`
  (скачивается автоматически; jar не модифицируется, патчи подгружаются
  отдельным каталогом `celestial-fix`)

### Сборка и запуск

```powershell
.\build.cmd     # build\launcher-app\CelestialLauncher\CelestialLauncher.exe + zip
.\run.cmd       # запустить лаунчер без упаковки

# то же самое вручную:
.\gradlew prepareAq1Fix prepareShieldBreakFix   # патч-классы в build/celestial-fix и run/celestial-fix
.\gradlew packageLauncher launcherZip           # app-image + build/distributions/*.zip
.\gradlew launcher                              # окно лаунчера без упаковки
```
